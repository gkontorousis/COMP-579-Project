# Reference slice (Liu et al. stock-trading / `rlstock`)

This folder is a **curated copy** of files from the upstream project, kept for local reference while re-implementing the environment and reproducing the paper’s setup.

**Original repository:** [hust512/DQN-DDPG_Stock_Trading](https://github.com/hust512/DQN-DDPG_Stock_Trading)

We included only what is needed to follow the **Liu et al. (NeurIPS 2018) stock-trading** work as realized in this codebase: the `rlstock` gym env sources, the entry `run.py`, the Dow Jones 30 daily data, and a flat copy of the data under `Data/` into the project root `data/` folder. The original repo’s long setup guide is saved here as [`original_README.md`](original_README.md). This is not a full clone of the project.
