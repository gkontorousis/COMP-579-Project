\begin{abstract}
Stock trading strategy plays an important role in portfolio management, but finding an effective strategy is difficult in complex and dynamic financial markets. In this project, we reproduce a deep reinforcement learning approach for stock trading based on the formulation of Liu et al.\ \cite{liu2018practical}. We model the trading process as a finite-horizon Markov decision process, where the agent observes current cash, stock prices, and portfolio holdings, then learns buy, sell, and hold decisions that maximize portfolio value over time. Using the same historical Dow Jones data split as the original paper, we train and evaluate a DDPG agent and compare it against DJIA and a min-variance portfolio baseline. We also evaluate TD3, a more stable extension of DDPG. Our results show that reinforcement learning outperforms the min-variance baseline, and that TD3 achieves stronger performance than DDPG in both cumulative return and Sharpe ratio. This suggests that TD3's stability improvements are useful for stock-trading environments where value estimates and policy updates can be noisy.
\end{abstract}

\section{Background and Motivation}

Recent work has modeled stock trading as a Markov decision process, allowing reinforcement learning methods to optimize sequential trading decisions directly rather than relying on separate return forecasting and portfolio optimization stages \cite{liu2018practical}. In the target paper, Liu et al.\ formulate the trading state using current stock prices, portfolio holdings, and remaining cash balance, and train a Deep Deterministic Policy Gradient (DDPG) agent to maximize changes in portfolio value over time \cite{liu2018practical}. Their results show that this approach outperforms both the Dow Jones Industrial Average (DJIA) and a classical min-variance portfolio baseline in terms of cumulative return and Sharpe ratio \cite{liu2018practical}.

\section{MDP Formulation and State Space}

Following Liu et al.\ \cite{liu2018practical}, we model the stock-trading problem as a finite-horizon Markov decision process (MDP). At each trading day, the agent observes the current portfolio state, chooses a trading action for each stock, corresponding to the number of shares to buy or sell, and receives a reward based on the resulting change in portfolio value. In our implementation, the MDP is deterministic with respect to the fixed historical price series: once the dataset split and the agent's action are fixed, the next state is fully determined. A schematic of this trading loop is provided in Appendix~\ref{app:mdp_diagram}.

\paragraph{State Space.}
The observed state is a continuous vector containing the agent's cash balance, the current adjusted close prices of all selected stocks, and the number of shares currently held in each stock. Although the original paper describes the Dow Jones 30 setting, our filtered dataset contains 28 tradable stocks. Therefore, the observation vector has length 57:
\[
s_t =
\left[
b_t,
p_t^{(1)}, \ldots, p_t^{(28)},
h_t^{(1)}, \ldots, h_t^{(28)}
\right],
\]
where $b_t$ is the available cash balance, $p_t^{(i)}$ is the adjusted close price of stock $i$ on day $t$, and $h_t^{(i)}$ is the number of shares held for stock $i$. Equivalently, index 0 stores cash, indices 1--28 store prices, and indices 29--56 store holdings.

At the beginning of each episode, the environment is reset with an initial cash balance of \$10{,}000, the adjusted close prices from the first day of the selected split, and zero holdings for all stocks:
\[
b_0 = 10000, 
\qquad
h_0^{(i)} = 0 \quad \forall i.
\]
The observation space is represented as a nonnegative continuous box, since cash, prices, and holdings are all constrained to be nonnegative.

\paragraph{Action Space.}
The action is a 28-dimensional vector, with one trade signal per stock:
\[
a_t =
\left[
a_t^{(1)}, \ldots, a_t^{(28)}
\right].
\]
The declared action space is continuous with bounds $[-5,5]$ for each stock. However, before execution, each action is clipped, rounded, and cast to an integer. Thus, the effective action for each stock is
\[
a_t^{(i)} \in \{-5,-4,\ldots,0,\ldots,4,5\}.
\]
A negative value means selling shares, a positive value means buying shares, and zero means holding the current position:
\[
a_t^{(i)} < 0 \Rightarrow \text{sell}, 
\qquad
a_t^{(i)} > 0 \Rightarrow \text{buy},
\qquad
a_t^{(i)} = 0 \Rightarrow \text{hold}.
\]

The trading constraints are long-only. The agent cannot short-sell, so holdings are never allowed to become negative. Similarly, buy orders are limited by the available cash balance, meaning the agent can only purchase shares it can afford at the current day's prices. The environment does not include transaction costs, slippage, taxes, or borrowing.

\paragraph{Transition Dynamics and Reward.}
At each time step, the environment first computes the portfolio value before trading:
\[
V_t = b_t + \sum_{i=1}^{28} p_t^{(i)} h_t^{(i)}.
\]
It then applies the agent's sell and buy actions using the current day's adjusted close prices. After trades are executed, the environment advances to the next trading day. Cash and holdings are carried forward after the trade execution, while the price vector is replaced by the next day's prices.

The reward is the change in total mark-to-market portfolio value:
\[
r_t = V_{t+1} - V_t,
\]
where
\[
V_{t+1} = b_{t+1} + \sum_{i=1}^{28} p_{t+1}^{(i)} h_{t+1}^{(i)}.
\]
Thus, the agent is directly rewarded for increasing total portfolio value from one trading day to the next. This matches the reward structure used by Liu et al., where the goal is to learn a policy that maximizes cumulative portfolio growth over the trading horizon \cite{liu2018practical}.

\paragraph{Episode Structure.}
Each episode corresponds to one complete pass through a selected date split. The data are divided using the same periods as the original paper: training from 2009--2014, validation during 2015, and testing/trading from 2016 to 2018. The episode terminates when the environment reaches the final trading day of the current split.

Overall, the environment can be summarized as a 28-asset, long-only, no-cost, daily rebalancing MDP. The state is composed of cash, current prices, and current holdings; the action is a bounded integer buy/sell vector; and the reward is the next-day change in mark-to-market portfolio value.

\section{DDPG}

Deep Deterministic Policy Gradient (DDPG) is an off-policy actor-critic algorithm designed for continuous action spaces \cite{lillicrap2015}. This makes it suitable for the trading environment, where the agent outputs one action value per stock before the environment converts these values into bounded buy, sell, or hold decisions. DDPG maintains two main neural networks: an actor and a critic. The actor $\mu(s|\theta^\mu)$ maps the current state $s_t$ to an action $a_t$, while the critic $Q(s,a|\theta^Q)$ estimates the expected return of taking action $a_t$ in state $s_t$.

% maybe either here or in implementation mention details about how we use a library for DDPG and TD3?
To improve training stability, DDPG uses a replay buffer and target networks. The replay buffer stores past transitions $(s_t,a_t,r_t,s_{t+1})$, allowing the agent to train on randomly sampled mini-batches instead of highly correlated consecutive market observations. Target actor and critic networks are slowly updated versions of the main networks, and are used to compute more stable temporal-difference targets. Exploration is added by perturbing the actor's selected action with noise during training. A full DDPG training outline is included in Appendix~\ref{app:algorithms}. In this project, DDPG serves as the main reproduced algorithm because it is the method used in the original stock-trading paper \cite{liu2018practical}.

\section{TD3}

Twin Delayed Deep Deterministic Policy Gradient (TD3) is an extension of DDPG designed to reduce instability and overestimation bias in actor-critic learning \cite{fujimoto2018}. Like DDPG, TD3 uses an actor network to select continuous actions and critic networks to estimate state-action values. However, TD3 modifies the learning procedure in three important ways: it uses two critic networks, delays actor updates, and adds smoothing noise to target actions.

The twin critics address overestimation bias by computing the target value using the smaller estimate from two critic networks. This makes the update more conservative and reduces the chance that the actor exploits overly optimistic value estimates. TD3 also updates the actor less frequently than the critics, allowing value estimates to improve before the policy is changed. Finally, target policy smoothing adds clipped noise to the next action, making the critic less sensitive to sharp or unreliable peaks in the learned value function. A full TD3 training outline is included in Appendix~\ref{app:algorithms}. We include TD3 as a stronger comparison to DDPG in the same trading environment, especially because stock-trading rewards can be noisy and sensitive to small policy changes.

\section{Implementation}

The experiments were implemented using Stable-Baselines3 versions of DDPG and TD3 \citep{stable-baselines3}, with both algorithms run through the same training and evaluation pipeline. Each model used the reproduced stock-trading environment and was trained on daily price data for the Dow Jones constituent stocks over the selected training date range, with DJIA index prices provided separately for benchmark comparison.

Hyperparameters were tuned with Optuna using 10 trials per algorithm. After tuning, each algorithm was trained for 30 episodes and evaluated across three random seeds, 42, 43, and 44. The seed runs were executed in parallel, and final results were aggregated by reporting the mean and standard deviation of the agent metrics across seeds.

For consistency, DDPG and TD3 were launched with the same experimental settings: three seed workers, three Optuna jobs, and controlled CPU thread counts per job. The main difference between the two runs was the selected algorithm and the best hyperparameters found independently by Optuna.


\section{Results and Discussion}

Table~\ref{tab:trading_results} summarizes the final test-period performance of DDPG, TD3, the min-variance baseline, and DJIA. Each reinforcement learning result is reported as the mean across three random seeds, with standard deviations shown in parentheses. Both RL agents outperformed the min-variance portfolio in final portfolio value and annualized return. DDPG slightly outperformed DJIA in return, but its mean Sharpe ratio was approximately equal to DJIA, suggesting that its higher return came with slightly higher risk. TD3 produced the strongest overall result, achieving the highest final portfolio value, annualized return, and Sharpe ratio.

The results partially reproduce the trend reported by Liu et al.\ \cite{liu2018practical}: reinforcement learning can outperform the classical min-variance baseline in this trading environment. However, our reproduced DDPG result is weaker than the original paper's reported DDPG performance. In our runs, DDPG achieved a mean final portfolio value of \$16{,}141.47, while the original paper reported \$19{,}791. This gap is likely due in part to computational limitations: our models were trained for a relatively limited number of episodes and Optuna trials, while the original paper does not fully specify the hyperparameter search process or training budget used to obtain its final result. As a result, our reproduction may not have matched the amount of tuning or training needed to reach the strongest DDPG policy. DDPG also only matched DJIA on Sharpe ratio, rather than clearly exceeding it.

TD3 performed better than DDPG under the same experimental setup. Its mean final portfolio value was \$16{,}918.53 compared to DDPG's \$16{,}141.47, and its mean Sharpe ratio was 1.68 compared to DDPG's 1.51. This is consistent with the design motivation behind TD3: DDPG can be sensitive to noisy or overestimated critic values, which may lead the actor toward unstable trading decisions. TD3 reduces this issue by using two critics and taking the smaller target value, delaying policy updates, and smoothing target actions \cite{fujimoto2018}.

More broadly, the stronger TD3 result suggests that stability may matter more than raw algorithmic flexibility in this trading environment. The action space is continuous before being rounded into integer trades, and the reward signal depends on noisy daily portfolio changes. In this setting, small errors in the critic can push the actor toward trades that appear profitable under the learned value function but do not generalize well over the test period. Since DDPG relies on a single critic, it is more exposed to this kind of overestimation error. TD3's clipped double-Q update makes the target value more conservative, while delayed policy updates give the critics more time to improve before the actor is changed. This likely helped TD3 avoid some unstable policy updates and produce better risk-adjusted returns.

These results also suggest a direction for future work. Rather than only increasing model complexity, future experiments should focus on improving the realism and robustness of the trading setup. This includes longer training budgets, broader hyperparameter searches, transaction costs, slippage, larger stock universes, and evaluation on additional market periods. It would also be useful to compare TD3 against other modern off-policy methods such as Soft Actor-Critic, and to test whether the advantage of TD3 remains when the environment includes more realistic trading frictions.

\section{Conclusion}

We reproduced the stock-trading reinforcement learning setup of Liu et al.\ \cite{liu2018practical} using the same MDP formulation and historical Dow Jones data split. Our DDPG results followed the main trend of the original paper by outperforming the min-variance baseline, though they were weaker than the reported original results, likely due to a smaller training and hyperparameter-tuning budget and uncertainty around the original tuning procedure.

TD3 achieved the strongest performance in our experiments, outperforming DDPG in final portfolio value, annualized return, and Sharpe ratio. Overall, these results suggest that while DDPG can learn useful trading behavior in this environment, TD3 provides a more stable and effective alternative for this reproduced stock-trading task.

\section{Algorithm Details}
\label{app:algorithms}
\FloatBarrier

\begin{algorithm}[H]
\caption{DDPG}
\label{alg:ddpg}
\begin{algorithmic}[1]
\State Initialize actor network $\mu(s|\theta^\mu)$ and critic network $Q(s,a|\theta^Q)$
\State Initialize target networks $\mu'$ and $Q'$ with the same weights
\State Initialize replay buffer $\mathcal{R}$
\For{each episode}
    \State Receive initial state $s_1$
    \For{each time step $t$}
        \State Select action $a_t = \mu(s_t|\theta^\mu) + \mathcal{N}_t$
        \State Execute action $a_t$, observe reward $r_t$ and next state $s_{t+1}$
        \State Store transition $(s_t,a_t,r_t,s_{t+1})$ in $\mathcal{R}$
        \State Sample a mini-batch of transitions from $\mathcal{R}$
        \State Compute target:
        \[
        y_i = r_i + \gamma Q'(s_{i+1}, \mu'(s_{i+1}))
        \]
        \State Update critic by minimizing:
        \[
        L = \frac{1}{N}\sum_i \left(y_i - Q(s_i,a_i)\right)^2
        \]
        \State Update actor using the policy gradient:
        \[
        \nabla_{\theta^\mu}J \approx
        \frac{1}{N}\sum_i
        \nabla_a Q(s,a)|_{s=s_i,a=\mu(s_i)}
        \nabla_{\theta^\mu}\mu(s_i)
        \]
        \State Soft-update target networks:
        \[
        \theta^{Q'} \leftarrow \tau \theta^Q + (1-\tau)\theta^{Q'},
        \qquad
        \theta^{\mu'} \leftarrow \tau \theta^\mu + (1-\tau)\theta^{\mu'}
        \]
    \EndFor
\EndFor
\end{algorithmic}
\end{algorithm}

\begin{algorithm}[t]
\caption{TD3}
\label{alg:td3}
\begin{algorithmic}[1]
\State Initialize actor network $\mu(s|\theta^\mu)$
\State Initialize two critic networks $Q_1(s,a|\theta^{Q_1})$ and $Q_2(s,a|\theta^{Q_2})$
\State Initialize target networks $\mu'$, $Q'_1$, and $Q'_2$
\State Initialize replay buffer $\mathcal{R}$
\For{each episode}
    \State Receive initial state $s_1$
    \For{each time step $t$}
        \State Select action $a_t = \mu(s_t|\theta^\mu) + \mathcal{N}_t$
        \State Execute action $a_t$, observe reward $r_t$ and next state $s_{t+1}$
        \State Store transition $(s_t,a_t,r_t,s_{t+1})$ in $\mathcal{R}$
        \State Sample a mini-batch of transitions from $\mathcal{R}$
        \State Add clipped noise to the target action:
        \[
        \tilde{a}_{i+1} = \mu'(s_{i+1}) + \epsilon,
        \qquad
        \epsilon \sim \mathrm{clip}(\mathcal{N}(0,\sigma), -c, c)
        \]
        \State Compute target using the smaller critic value:
        \[
        y_i = r_i + \gamma \min_{j=1,2} Q'_j(s_{i+1}, \tilde{a}_{i+1})
        \]
        \State Update both critics by minimizing:
        \[
        L_j = \frac{1}{N}\sum_i \left(y_i - Q_j(s_i,a_i)\right)^2,
        \qquad j \in \{1,2\}
        \]
        \If{policy update step}
            \State Update actor using $Q_1$:
            \[
            \nabla_{\theta^\mu}J \approx
            \frac{1}{N}\sum_i
            \nabla_a Q_1(s,a)|_{s=s_i,a=\mu(s_i)}
            \nabla_{\theta^\mu}\mu(s_i)
            \]
            \State Soft-update target networks
        \EndIf
    \EndFor
\EndFor
\end{algorithmic}
\end{algorithm}
